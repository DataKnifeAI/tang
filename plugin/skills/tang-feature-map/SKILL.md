# tang-feature-map

## Steps

1. Open `docs/FEATURE_MAP.md` (create from Tang template if missing).
2. Add/update a single row: Feature | Entry point | Verify.
3. Keep cells short — paths and test targets, not essays.
4. Remove stale rows when surfaces die.
5. Point other skills at the map before broad search when possible.
