# Playbook: new-project

1. Confirm name + language pack with the user if missing.
2. Follow `tang-new-project` / run `tang init <name> --lang <pack>`.
3. Ensure `make verify` is reachable (may be a stub until real tests exist).
4. Print Slashbay allowlist hint and point at Tang `docs/SLASHBAY.md` + `docs/CATALOG.md`.
